## 📌 Sobre o projeto

O **A11Y para Todos** é um projeto educacional desenvolvido com o tema **Acessibilidade Digital e Web para Todos**.

A proposta surgiu a partir da percepção de que estar conectado à internet não significa, necessariamente, conseguir utilizá-la com autonomia.

Sites podem apresentar diversas barreiras para pessoas com deficiência ou com diferentes formas de interação, como ausência de descrição em imagens, baixo contraste, navegação limitada ao mouse, formulários sem identificação adequada e conteúdos multimídia sem recursos acessíveis.

Por isso, o projeto busca apresentar o tema de maneira prática, visual e interativa, mostrando tanto os principais problemas quanto possíveis soluções para construir experiências digitais mais inclusivas.

## 🎯 Tema

> **Acessibilidade Digital e Web para Todos**

Nosso projeto aborda como sites, plataformas e serviços digitais podem ser desenvolvidos de maneira mais acessível, considerando diferentes formas de perceber, compreender e interagir com o conteúdo.

---

## 💭 Por que escolhemos esse tema?

A internet está presente em atividades fundamentais como estudar, trabalhar, comunicar-se, utilizar serviços públicos e acessar informações.

Entretanto, muitas páginas ainda são construídas sem considerar pessoas que utilizam leitores de tela, navegação por teclado, ampliação de conteúdo, legendas, Libras ou outras tecnologias e estratégias de acesso.

Escolhemos esse tema porque acreditamos que **inclusão digital não significa apenas permitir que alguém entre em um site, mas garantir que essa pessoa consiga realmente utilizá-lo**.

---

## 🚧 Qual problema o projeto pretende abordar?

O projeto aborda a existência de **barreiras de acessibilidade em ambientes digitais**.

Alguns exemplos são:

- imagens sem texto alternativo;
- baixo contraste entre texto e fundo;
- textos excessivamente pequenos;
- páginas impossíveis de navegar apenas pelo teclado;
- formulários sem rótulos adequados;
- links pouco descritivos;
- ausência de foco visual;
- vídeos sem legendas;
- estruturas HTML inadequadas;
- interfaces que dependem exclusivamente de cor ou mouse.

Esses problemas podem transformar tarefas aparentemente simples em obstáculos para determinados usuários.

---

## 👤 Quem é afetado?

As barreiras digitais podem afetar pessoas com:

- deficiência visual;
- baixa visão;
- deficiência auditiva;
- limitações motoras;
- necessidades cognitivas;
- dificuldades temporárias de interação.

Além disso, recursos de acessibilidade também podem beneficiar pessoas idosas, usuários utilizando telas pequenas, pessoas em ambientes muito iluminados ou barulhentos e até usuários com lesões temporárias.

---

## 🎓 Por que isso é importante para a Educação Inclusiva?

Recursos digitais fazem parte do cotidiano escolar.

Materiais, vídeos, sistemas acadêmicos, formulários, atividades e plataformas educacionais precisam permitir que diferentes estudantes consigam participar das mesmas experiências.

A acessibilidade contribui para que a tecnologia funcione como uma ferramenta de inclusão, e não como uma nova barreira.

---

## 🧠 Principais conceitos que aprendemos

### ♿ 1. Acessibilidade deve começar no projeto

Acessibilidade não deve ser tratada apenas como uma correção feita depois que uma página está pronta.

Ela precisa ser considerada desde o planejamento da interface.

### 🌐 2. WCAG

As **Web Content Accessibility Guidelines** são diretrizes internacionais utilizadas como referência para acessibilidade na Web.

Elas são organizadas em quatro princípios:

**Perceptível • Operável • Compreensível • Robusto**

### ⌨️ 3. Existem diferentes formas de utilizar a Web

Nem todas as pessoas utilizam mouse.

Usuários podem navegar utilizando teclado, leitores de tela, controle por voz, ampliação, dispositivos assistivos e outras tecnologias.

### 🧩 4. Pequenos detalhes podem criar grandes barreiras

Uma imagem sem descrição, um botão sem identificação ou um contraste inadequado podem impedir que determinados usuários compreendam ou utilizem uma página.

## 🛠️ Conserte o Site

Uma das principais experiências do projeto é o jogo:

# **CONSERTE O SITE**

O jogador recebe uma página propositalmente desenvolvida com problemas de acessibilidade.

Seu objetivo é observar a interface, localizar os erros e descobrir como poderiam ser corrigidos.

O jogo apresenta três fases progressivas:

**Fase 1 — Problemas básicos**

Contraste, tamanho de texto e imagens sem descrição.

**Fase 2 — Estrutura**

Formulários, labels, títulos, links e botões.

**Fase 3 — Especialista**

Teclado, foco, tecnologias assistivas e conteúdos multimídia.

Ao encontrar um problema, o jogador recebe:

✅ explicação do erro  
🛠️ forma de correção  
⭐ pontuação  
💡 possibilidade de utilizar dicas  

A ideia é transformar conceitos de acessibilidade em uma experiência prática.
